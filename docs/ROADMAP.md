## 3. События
1. Git: коммит → подарок, push → сани, pull → письма, ветка → погода, конфликт → метель (optional `Git4Idea`). Подарки за незапушенные коммиты и сани с эльфами на push готовы: шина `events/`, `git/GitCommitWatcher`, `drift/GiftPile`, `drift/Delivery`.
2. Тесты: зелёные/красные (`SMTRunnerEventsListener`).
3. Сборка: IDEA и Gradle, сани в progress bar, золотая волна, падающая сосулька.
4. Код: быстрая печать, большое удаление, reformat, breakpoint.
5. Время: утро, вечер, простой, 2 часа без перерыва, погода за окном.
6. Ограничение частоты пролётов.
