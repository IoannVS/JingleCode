# Jingle Code: спецификация

Всё ниже нарисовано и анимировано в макете `docs/mockup/jingle-code-mockup.html`. Если описание и макет расходятся, прав макет.

## 1. Постоянный декор

| Элемент | Где | API | Риск |

## 2. Снег в редакторе (настройка, три режима + выкл)
1. **В пустом месте** (по умолчанию): снежинки летят справа от кода и в пустых строках, на текст не попадают. Долетев до строки, ложатся на неё сверху сугробиком до 3 пикселей. Геометрия строк из `Editor` (`logicalPositionToXY`, видимая область).
2. **Поверх с паузой при печати**: снег по всему редактору, при нажатии клавиши пропадает, через ~2,5 с тишины пойдёт снова.
3. **За текстом**: тусклые снежинки под текстом. Требует внутреннего API, риск выше.

## 3. События
Все анимации 1–3 секунды, только в зонах декора. Пролёты саней и салюты не чаще раза в 10 минут (настраивается).

**Git** (optional `Git4Idea`)
- Коммит → под ёлкой в панели Project падает подарок. В полночь кучка обнуляется.
- Push → упряжка Санты (сани + два оленя, у ведущего красный нос) пролетает по свободной части тулбара.
- Merge-конфликт → метель в щелях, гирлянда мигает красным.
- Pull → в почтовый ящик падают письма, по одному на входящий коммит.
- Смена ветки → своя погода: main ясно, feature снег, hotfix метель. Сопоставление веток и погоды настраивается.

**Сборка и тесты**
- Долгая сборка или индексация → упряжка тянет progress bar и оставляет за собой гирлянду (`ProgressBarUI` или своя отрисовка индикатора).
- Запуск или сборка прошли (любая Run-конфигурация или Build, завершились сами, код 0) → гирлянда заливается золотом, мерцает и возвращается к своим цветам; в пустых местах тулбара салют, каждый раз разный: 5–8 залпов разных видов, цветов и размеров в случайных местах.
- Запуск или сборка упали (код не 0 или ошибки сборки) → больше половины сосулек под тулбаром и большинство под активной вкладкой срываются, падают до низа окна поверх всего, в том числе кода, разбиваются там на осколки и сразу отрастают; пока падают, гирлянда мигает только красными, в трёх оттенках. Тесты отдельно не выделяем, каждое событие отрабатываем, без ограничения частоты.
- Тесты зелёные → снеговик машет, салют в тулбаре, уголёк исчезает.
- Тесты красные → в носке у камина в строке состояния уголёк, пока тесты не позеленеют.

**Работа с кодом**
- Быстрая печать → камин в строке состояния горит ярче, искрит, потом затихает.
- Удалено много строк разом → по гирлянде над строкой состояния проезжает снегоуборщик.
- Reformat code → снежинки в панели Project выстраиваются рядами.
- Breakpoint → снизу щели выглядывает пингвин, при продолжении прячется.

**Время и человек**
- Утро, первое открытие IDE → камин разгорается из углей.
- Вечер (после 17:00) → в деревне больше окон, луна, звёзды.
- Простой 15+ минут → тулбар и вкладки заметает. Первое нажатие клавиши или клик стряхивает снег.
- 2 часа без перерыва → снеговик с кружкой какао.
- Снег за окном (погода по городу, Open-Meteo без ключа) → снег в щелях и в панели Project.

**Календарь** (зависит от настройки «Язык и праздники»)
- 6 декабря → подарок в носке.
- 31 декабря 00:00 → салют по всему тулбару, все огни горят разом, звезда на ёлке.
- 7 января → огни гирлянды становятся золотыми колокольчиками, звезда на ёлке.
- 13–14 января, Старый Новый год → маленький повтор салюта.
- Конец сезона → снеговик тает в лужу, украшения убираются сами.

## 4. Пасхалки (не документируются в описании плагина)
- `class Magpie` / `soroka` → сорока-воровка утаскивает лампочку из гирлянды, после удаления класса лампочка возвращается. (Гринча не используем.)
- `// ho ho ho` в комментарии → Санта пролетает, за ним пиксельное «HO HO HO».
- `letItSnow` в коде → 10 секунд густого снегопада.
- `while (true)` → пингвин катается на коньках по щели, пока цикл есть в файле.
- Konami code (↑↑↓↓←→←→BA) в пустом редакторе → мини-игра: сани ловят подарки, без нажатий играют сами.
- 10 кликов по снеговику → заяц утаскивает морковку.
- Пустой редактор 5 минут → у камина сворачивается кот.
- Коммит с 23:00 до 5:00 → нос ведущего оленя светит вперёд.
- Коммит 31 декабря после 22:00 → в носке мандарин.
- Йети раз в сезон в случайный день проходит по нижней щели.
- Два открытых проекта с одним именем из разных папок → уведомление «Ирония судьбы… 3-я улица Строителей, дом 25?» (только для русского региона).

## 5. Отложено, держим в уме
Лавина на force push; дым из труб деревни, пока запущено приложение; сосульки техдолга (длина по числу TODO); stash закапывает подарок, pop откапывает; снегирь на cherry-pick; сани задом на revert; Санта с мешком на тег/релиз; снежок в снеговика на исключение в консоли; шаг пингвина на step over; огни при окончании индексации; сугроб от предупреждений, звезда при нуле; coverage → снег в деревне; снежинка вместо значка закладки на полях; эльф на rename; второй снеговик при подключении гостя Code With Me.

## 6. Настройки (Settings → Appearance → Jingle Code)
- Включить плагин; сезон: авто (1 декабря – 14 января) / всегда / выкл.
- Язык и праздники: авто по региону / русский / английский. Определяет даты Рождества, Старый Новый год, «Иронию судьбы», мандарин и тексты интерфейса.
- По одному переключателю на каждый элемент декора; элементы на внутреннем API помечены как экспериментальные.
- Всплывающие окна и меню (эксп.): снег на всплывающих окнах и уведомлениях, снег на контекстных меню, см. `docs/POPUPS.md`.
- Режим снега в редакторе: выкл / в пустом месте / поверх с паузой / за текстом.
- События: включить, ограничение частоты для саней и салютов.
- Режим гирлянды (есть: мерцание, бегущий огонь, перелив, тёплый белый).
- Стиль деревни: хутор на холме / долина / улица в гору / поляна в лесу / случайный (раз в день по дате), см. `docs/VILLAGE.md`.
- Звук: выкл по умолчанию.

## 7. Совместимость
- Основа на `com.intellij.modules.platform`: IDEA, PyCharm, WebStorm, GoLand, PhpStorm, RubyMine, CLion, DataGrip, RustRover, Rider, Android Studio. Fleet не поддерживается.
- Git-события: optional-зависимость на `Git4Idea`.
- Тесты, запуск, отладчик, исключения: платформенные API (`SMTRunnerEventsListener`, `ExecutionListener`, `XDebuggerManagerListener`).
- Запуски и сборка: во всех IDE — завершение Run-конфигураций (`ExecutionListener`), плюс действие Build (`ProjectTaskListener`, optional `com.intellij.modules.lang`). В Rider и CLion кнопка Build может не давать событий: проверить.
- Классический UI без «островов»: для гирлянды нужен запасной вариант по краям панелей.
- Удалённая разработка (Gateway): проверить, где рисуется декор.

## 8. Название и локализация
- **Название: Jingle Code** (решено). Сезон заканчивается на Старом Новом годе, это и делает рождественское имя уместным. Другие кандидаты были: Snowed In, Let It Code, 8-bit Winter. Имя свободно в Marketplace (проверено 30 октября 2026: поиск «Jingle Code» пуст, id `io.github.ioannvs.jinglecode` не занят).
- Имя плагина одно на все языки (`<name>` не локализуется). В описание добавить строку и теги по-русски: сугроб, новый год, зима.
- Тексты интерфейса: `messages/JingleCodeBundle.properties` + `JingleCodeBundle_ru.properties`, плюс собственный переключатель языка в настройках, потому что русского языкового пакета у JetBrains нет.
