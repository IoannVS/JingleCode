# Деревня на фоне редактора: стили и генератор

Эталон: `docs/mockup/jingle-code-village.html` (открыть в браузере). Опубликован: https://claude.ai/artifact/BnaDunv61d8Jyc3gPyCKTn. Если описание и макет расходятся, прав макет. Код рисования в макете (`drawHouse`, `pine`, `birch`, `fence`, `v1`…`v4`) переносим в Kotlin один в один, по пикселям.

## Почему переделываем
Текущая деревня однородная: домики одинаковой формы стоят с равным шагом, снег на крышах лежит одинаково. Иван принял четыре стиля из макета, между ними можно переключаться.

## Общие правила композиции
- Никакого равного шага. Дома стоят группами, между группами пустой снег.
- Асимметрия и доминанта: в каждой сцене есть одна главная точка (часовня, вершина, изба на поляне).
- Ёлки кучками разного роста, с прогалинами, иногда берёзы.
- Земля неровная (холмы через `bump`, лёгкая синусоида), декор прилегает к нижнему краю редактора по всей ширине, без прямоугольников.
- Цвета насыщенные, без прозрачности. Глубина достигается размером и тоном.
- Детали по зерну (`seed`): зерно меняется раз в день, композиция стиля остаётся, детали (цвета крыш, наличники, сосульки, гирлянды) разные.

## Четыре стиля
1. **Хутор на холме** (`HILL_FARM`, `v1`). Плотная асимметричная группа на холме справа: терем, изба, домик, часовня-доминанта, баня. Слева одинокий амбар с забором и стогом, берёзы, кучки ёлок. Фонарь, санки, снеговик.
2. **Долина** (`VALLEY`, `v2`). Три плана. Дальний: горы со снежными шапками, между вершинами видно небо; на склоне маленькая деревня с огнями, дымками и шпилем; по серпантину едут сани с фонарём. На правом склоне большой горы горнолыжка: две трассы змейкой, кресельный подъёмник с опорами и движущимися креслами, лыжники, база с окнами и флагом, вечером фонари вдоль трассы. Средний: снежная гряда, лес куртинами, замёрзший пруд с двумя конькобежцами. Передний: группа домов слева, баня у ёлок справа, середина свободна.
3. **Улица в гору** (`UPHILL_STREET`, `v3`). Улица по диагонали поднимается к часовне на вершине, за ней спуск к мельнице и лесу. Неровный ритм: поле с берёзами и стогом, изба с баней вплотную у подножия, колодец, терем, вершина. Задний ряд домов выше по склону и частично закрыт передним.
4. **Поляна в лесу** (`FOREST_CLEARING`, `v4`). Густой лес по краям в два тона, в середине поляна с одной избой: свет в окнах, густой дым, дрова, снеговик, санки.

## Генератор домов
Дом собирается из параметров (`randomSpec(type, r)` в макете → `HouseSpec` в Kotlin): тип, ширина, высота, этажность, стены (брёвна, доски, красный, синий, жёлтый, камень), форма и цвет крыши, крутизна, труба, окна, резные наличники, украшение (гирлянда, венок, ничего).

Типы: изба, терем (2 этажа), домик, баня (односкатная крыша, густой дым), амбар (ворота крестом), часовня (купол с крестом), мельница (крутятся лопасти), шалаш (крыша до земли).

Снег зависит от ветра (`wind` ±1) и крутизны: на наветренной стороне больше, с крутой крыши съезжает, у стены надуло сугроб, сосульки не везде.

## Анимация (общий `JingleAnimator`, 6 кадров по 120–150 мс)
Дым из труб, мерцание звёзд, лопасти мельницы, сани на серпантине, кресла подъёмника, лыжники, конькобежцы, флаг. Вечер (после 17:00): горят окна и фонари, луна, больше звёзд. Если анимация фона дорогая, допустимо перерисовывать фон реже, но движущиеся мелочи (дым, лыжники) не терять без согласования с Иваном.

## Настройки
Settings → Appearance → Jingle Code → «Деревня»:
- Стиль: Хутор на холме / Долина / Улица в гору / Поляна в лесу / Случайный.
- «Случайный»: выбирается раз в день по дате (стабильно в течение дня, не прыгает при перезапуске IDE).
- Смена стиля применяется сразу, без перезапуска (через `JingleCodeSettingsListener`).
- Тексты названий стилей в `JingleCodeBundle` (ru/en).

Kotlin: `enum class VillageStyle { HILL_FARM, VALLEY, UPHILL_STREET, FOREST_CLEARING, RANDOM }`, поле `villageStyle` в `JingleCodeSettings`, по классу-композиции на стиль за общим интерфейсом (например `VillageScene.draw(canvas, width, height, seed, frame, evening)`), общий `HouseRenderer`.
