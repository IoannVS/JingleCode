Что делает каждое событие

  • Коммит: под ёлкой в панели Project падает новый подарок. В полночь кучка обнуляется.
  • git push: упряжка Санты пролетает через свободную часть тулбара.
  • Конфликт при merge: метель в щелях между панелями, гирлянда тревожно мигает.
  • Сборка прошла: сани тянут progress bar, потом по гирлянде бежит золотая волна.
  • Сборка упала: сосулька срывается, падает по щели и разбивается внизу, огни на миг краснеют.
  • Тесты зелёные: снеговик машет руками, в тулбаре салют. Уголёк из носка исчезает.
  • Тесты красные: в носок у камина в строке состояния падает уголёк и лежит, пока тесты не позеленеют.
  • Утро: камин в строке состояния разгорается из углей.
  • Вечер: в деревне зажигаются окна, выходят луна и звёзды.
  • Отошёл на 15 минут: тулбар и вкладки заметает. Клик или клавиша, и снег осыпается.
  • 31 декабря, 00:00: салют по всему тулбару, все огни горят разом, на ёлке звезда.
  • Pull: в почтовый ящик у сугроба падают письма, по одному на входящий коммит.
  • Ветка: у каждой ветки своя погода. На main ясно, на feature идёт снег, на hotfix метель.
  • Быстро печатаешь: камин в строке состояния горит ярче и искрит. Работает и от настоящих нажатий клавиш на этой странице.
  • Удалил много строк: по гирлянде над строкой состояния проезжает снегоуборщик.
  • Reformat code: снежинки в панели Project выстраиваются ровными рядами.
  • Breakpoint: снизу из щели выглядывает пингвин и прячется, когда продолжаешь выполнение.
  • 2 часа без перерыва: у снеговика в руке появляется кружка какао с паром.
  • Снег за окном: если в твоём городе идёт снег, он идёт и в щелях, и в панели Project.
  • 6 декабря: в носке у камина лежит подарок от Николая.
  • 7 января: огни гирлянды становятся золотыми колокольчиками, на ёлке звезда.
  • Старый Новый год: маленький повтор салюта.
  • Конец сезона: снеговик тает, и украшения убираются сами. Кнопка возвращает зиму обратно.

Пасхалки

  • class Grinch: из щели выглядывает Гринч и утаскивает лампочку из гирлянды. Нажми ещё раз, как будто удалил класс, и лампочка вернётся.
  • // ho ho ho: Санта пролетает через тулбар и смеётся.
  • letItSnow: десять секунд густого снегопада во всех щелях.
  • while (true): пингвин катается на коньках по щели, пока цикл не уберёшь.
  • Konami code (↑↑↓↓←→←→BA, можно набрать на клавиатуре прямо здесь): в пустом редакторе внизу страницы мини-игра, ловишь подарки санями стрелками. Без нажатий сани ловят сами.
  • 10 кликов по снеговику в панели Project (можно кликать прямо по нему): прибегает заяц и утаскивает морковку.
  • Пустой редактор 5 минут: у камина сворачивается кот.
  • Коммит в 2 ночи: Санта летит, а нос Рудольфа светит вперёд.
  • Коммит 31-го в 23:00: в носке мандарин. Работать в Новый год? Держи.
  • Йети: раз в сезон, в случайный день, проходит по щели над строкой состояния.
  • Два проекта Winter из разных папок: уведомление про «Иронию судьбы».

Пролёты саней и салюты стоит ограничить, например не чаще раза в 10 минут, чтобы не надоели.
