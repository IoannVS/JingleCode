Ширина окна

Двор по правилам деревни: доминанта мастерская с часами (показывают реальное время) и флюгером, слева конюшня с забором и оленем у стога, справа большая ёлка с гирляндой и почта. На крыше гном чистит снег. Задача: подарки едут по жёлобу из чердака, гномы носят их в сани. Успех: ёлка вспыхивает золотом, Санта уезжает на санях. Ошибка: коробка лопается, ёлка мигает красным. Уведомление: снегирь приносит письмо в мешок. Снег по правилам деревни: сплошной, с белым гребнем и тенью на спусках. В узком окне конюшня и ёлка уходят.
