Окна Jingle Code

Всё, что сейчас за бортом: окна, общие для всех IDE JetBrains. Правила те же, что и для остального декора: поверх кода и текста не рисуем, декор держится за края и живёт только в пустых местах. Окна нарисованы упрощённо, пиксельный декор в масштабе ×3.

  • Одна реализация на все окна: шапка у инструментальных окон общая, поэтому снег появляется в Terminal, Run, Debug, Problems, Git и любых окнах других плагинов.
  • Только пустое место между вкладками и кнопками справа. Узкое окно, где места нет, остаётся без снега.
  • Снегирь изредка садится на сугроб, прыгает и улетает. В правом окне он прилетает чаще, чтобы было видно.

3. Сугроб в Terminal и Run

TerminalLocal
  • Пока внизу пусто, там лежит сугроб от края до края, как в панели Project: фонарик, ёлочка, следы.
  • Когда вывод доходит до сугроба, сугроб уезжает вниз и не мешает читать. После очистки возвращается.
  • То же для консолей Run, Debug и Services.

4. Значки на боковых полосках

риск средний
fun main() {
    println("Jingle Code")
}
  • Шапка снега на значках окон, на значке активного окна снег искрится.
  • Риск: значки подменяются через механизм подмены иконок, он публичный лишь наполовину. Значки других плагинов не трогаем. Отдельный переключатель.

8. Пустое место на боковых полосках

советую
class Sleigh(val reindeer: Int) { fun fly(to: Address) = println("Ho-ho-ho → $to") }
  • Слева внизу, под значками, сугроб со снеговиком. Снеговик иногда машет метлой, на него садится снегирь.
  • Справа время от времени сверху на верёвочке спускается эльф, болтает ногами, машет и забирается обратно.
  • Если значков много и места нет, декор не показывается. Если окно свёрнуто в полоску, тоже.

9. Полоса вкладок редактора

Sleigh.kt ×Gift.kt ×build.gradle.kts ×
data class Gift(val name: String, val address: Address)
  • Тот же снег, что в шапках окон: справа от последней вкладки, только в пустом месте. Когда вкладок много и места нет, снега нет.
  • Общий код с шапками окон, отдельная работа почти не нужна.

10. Diff

fun deliver(gift: Gift) {
val sleigh = Sleigh(reindeer = 8)
sleigh.load(gift)
sleigh.fly(to = gift.address)
}
 
fun wrap(gift: Gift) =
gift.copy(paper = Paper.RED)
 
fun deliver(gift: Gift) {
val sleigh = Sleigh(reindeer = 9)
sleigh.load(gift)
sleigh.checkList()
sleigh.fly(to = gift.address)
}
 
fun wrap(gift: Gift) =
gift.copy(paper = Paper.GOLD)
  • Разделитель между половинами: связки изменений остаются как есть, по разделителю провисает гирлянда, огни переливаются.
  • Внутри половин ничего не рисуем, код и подсветка изменений не трогаются.
  • Риск средний: разделитель Diff рисуется внутренним компонентом. Отдельный переключатель.
